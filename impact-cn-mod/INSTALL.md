# 汉化助手安装与使用

版本：0.5.3 · Chrome Manifest V3 · 本地测试包

这是供 Chrome 本地试用的源码包。当前词典699条、66个解释主题，其中财务442条、24个主题。本版新增账单分组和资金账户原生 Actions 菜单的5条固定标签。两页正常原生菜单操作、文字翻译及原文恢复已得到定向实网证据；翻译时原生菜单根节点的定位属性变化，严格属性验收尚未通过。完整财务正式验收仍需这项证据、报表完整结果、三类编辑表单及新原生AI回复。

## 安装 ZIP 包

1. 将 `impact-cn-mod-0.5.3.zip` 解压到一个固定位置。不要直接选择 ZIP 文件，也不要在安装后移动或删除解压目录。
2. 在 Chrome 地址栏输入 `chrome://extensions/`，打开扩展程序管理页。
3. 开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择**直接包含 `manifest.json` 的文件夹**。如果解压后有多层目录，进入到 `manifest.json` 所在的那层。
5. 确认扩展列表显示“汉化助手 0.5.3”，然后刷新已打开的 Impact 页面。

插件匹配 `https://demo.impact.com/*` 与 `https://app.impact.com/*`。需要使用自己的 Impact 登录会话；安装包不包含账号或登录状态。建议将 Impact 原站语言设为 **English** 后刷新，使用英文原文作为精细汉化的基准。

本包是供本地加载的 ZIP 源码包，没有发布到 Chrome 商店，也不是双击安装的 CRX 文件。

## 在 Impact 页面使用

在页面右侧找到“汉化助手”，展开即可看到两个独立开关。也可以从 Chrome 工具栏打开同名扩展；两处设置同步，开关选择会保存。

| 精细翻译 | AI辅助问题回答 | 效果 |
| --- | --- | --- |
| 开 | 开 | 显示校准后的中文，以及复杂概念旁的问号 |
| 开 | 关 | 显示中文，隐藏概念问号 |
| 关 | 开 | 保留原文，显示复杂概念旁的问号 |
| 关 | 关 | 显示原始页面 |

点击术语旁的 **?**，插件会打开 Impact 原有的 Ask Impact，填入只解释该术语的预设问题并发送。问题要求给出定义、联盟营销示例、口径与常见误解、界面用途及官方 HelpDoc 链接；实际回复由 Impact 生成。原生 AI 已有草稿时，插件会保留草稿并提示，避免覆盖正在编辑的问题。

拖动助手左侧的 **⠿ 把手** 可移动位置；位置只在当前页面保留，刷新后回到默认位置。“恢复默认位置”也能立即复位。把手获得键盘焦点后，可用方向键移动，按住 Shift 加快移动。

## 本版覆盖

- 已采集四个产品的共享侧边栏：Engage、Discover、Optimize、Protect，包括主菜单、展开子菜单和嵌套菜单。87 个不同英文标签对应 88 个有明确语境的词条；Optimize 按约定译为“多维分析”。
- 包含品牌侧 Dashboard 的已采集标签、主要指标和动态日期范围标签。
- 右上角 Help 问号菜单的 6 个入口，以及金额按钮展开的财务栏框：资金摘要、到期说明、财务入口和报表/账单凭证/设置三组子菜单。
- 财务导航的全部 15 个目的页面：财务总览、充值、伙伴资金转账、订阅与用量、月结报表、即将到期的伙伴付款、资金流水、伙伴付款账单、impact.com 服务费账单，以及常规设置、法律主体、账单分组、资金账户、充值付款方式、自动充值。包含已采集的正文、表头、筛选菜单和未提交表单。
- 账单分组和资金账户的 Actions 菜单包含已观察的编辑及文档设置标签；菜单打开不表示编辑表单已验收。
- 复杂财务概念旁提供独立问号，包括需补充资金、款项到期、月结日期口径、开账单方式、账单分组等。预设主题数不代表每个主题的原生 AI 回复均已逐一验收。
- 当前 Demo 订阅页只显示“订阅信息暂不可用”；自动充值设置因有待处理充值而禁用。已翻译实际提示，账户未开放的设置内容不计入验收。
- 其他业务页面正文尚未逐页校准。不同套餐或权限出现的新控件需要补充采集；`app.impact.com` 生产域尚未完成已登录验收。

插件保留名称、金额、日期、业务 ID、输入内容和原生 AI 回复。未收录的文本继续显示原文；不能处理图片、canvas、封闭 Shadow DOM 或跨域 iframe 中的文字。详细映射、修改原因与验证范围见 [LOCALIZATION_GUIDE.md](LOCALIZATION_GUIDE.md)，版本变化见 [CHANGELOG.md](CHANGELOG.md)。

## 更新与排查

更新时，将新版解压到新的固定文件夹，在 `chrome://extensions/` 先停用旧版，再加载新版并刷新 Impact。保留旧文件夹便于对照；加载后确认版本为0.5.3及两个开关状态。请只启用一个版本，避免重复显示。

如果没有看到中文，先确认扩展已启用、地址属于上述两个域、精细翻译已开启，然后刷新页面。看到问号但无法发送时，查看汉化助手的提示，确认原生 Ask Impact 可使用且没有未发送的草稿。关闭“AI辅助问题回答”可以暂时隐藏问号，不影响中文翻译。
