# impact.com助手安装与使用

候选版本：0.9.10 · Chrome Manifest V3

本包提供品牌平台已适配固定界面的本地中文翻译、单概念帮助和上线指引。当前加载版本、实页通过范围和未测内容统一见工程 PROJECT_STATE.md；候选版本号和合成检查不代表 Demo GC 已完成全部汉化。

## 安装与更新

1. 使用同版本的 `dist/impact-cn-mod-0.9.10/`，或先解压 `dist/impact-cn-mod-0.9.10.zip`。
2. 由用户手动打开 Chrome 扩展管理页，加载直接包含根 `manifest.json` 的目录。只启用一个开发版，保留解压目录及旧包。
3. 保留未保存表单；准备好后刷新正常 Impact 页，在助手中确认实际显示 `v0.9.10`。不要仅凭扩展管理页或目录名判断页面版本。

商店安装用户使用商店已发布版本；本候选不会因本地打包而自动送审、发布或替换商店版本。

## 两个独立开关

- 精细翻译：开启显示已适配中文，关闭恢复原文。
- AI辅助问题回答：显示或移除复杂概念问号，关闭时取消尚未发送的问题，不关闭翻译。

两个开关独立保存到 Chrome 本地扩展存储，在工具栏弹窗与各页面同步。普通菜单重挂会重新判定，无需反复拨动翻译开关。助手可拖动，位置只保留在当前页，刷新复位。

## 概念帮助与指引

点击已适配复杂概念旁的问号后，通过页面原有 Ask Impact 提问并要求对应官方链接。已有草稿、禁用状态或页面变化会阻止未发送请求；回复、引用及服务可用性由 Impact 平台决定。扩展没有自建AI后端，也不把当前业务行拼进问题。

“上线指引”提供八项说明；可定位步骤只提示位置，不代点原生按钮。阅读、操作声明、页面到达与真实业务成功分别判断。跨document无法核对Program来路时不恢复旧活动任务。退款与审核只提供说明和阅读标记。

Save／Next可能保存配置。订单、支付、安装授权、审核及发送请求须由有权人员自行决定；扩展不代替授权。

## 访问和数据边界

支持 `demo.impact.com` 与 `app.impact.com` 已适配品牌端组件，建议原站语言设为 English。四个精确 `ui.assets.impact.com` Checklist文档只提供受限翻译，不创建助手或发送概念问题；不增加任意网站或店铺权限。

只替换已收录固定Text。名称、金额、日期、业务ID、输入值、自定义内容、选中值及AI回复保持原样；未适配文案保持原文。DOM路径、组件和实际Shadow宿主共同限定词条，页面数据仍由Impact管理。

两个开关持久保存在local存储。指引的session检查点只含公开场景与有限临时状态，不含业务ID、业务值或操作声明；待到达边120秒内有效、读取即消耗。固定主题、授权与几何内部消息不携带业务正文。

术语和范围见 LOCALIZATION_GUIDE.md，变更见 CHANGELOG.md；包内交接入口见 HANDOFF.md。完整Demo GC覆盖进度由工程状态入口维护，不随候选包自称完成。
