# 汉化助手安装与使用

版本：0.6.1 · Chrome Manifest V3

为 Impact 品牌端提供中文界面和术语帮助，支持 `demo.impact.com` 与 `app.impact.com`。汉化在本地执行，概念问号使用页面已有的 Ask Impact。

包含 Engage 伙伴管理、申请与提案、自动化、活动与零售媒体、素材与商品、合同、报表和交易记录的固定界面文案。

## 安装

1. 将 `impact-cn-mod-0.6.1.zip` 解压到固定位置，或使用仓库中的 `impact-cn-mod/`。
2. 在 Chrome 地址栏输入 `chrome://extensions/`。
3. 开启右上角“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择直接包含 `manifest.json` 的文件夹。
5. 确认“汉化助手”已启用，再刷新 Impact 页面。

插件使用浏览器中已有的登录会话。建议将 Impact 原站语言设为 English。安装后请保留解压目录，只启用一个版本；ZIP 需要解压后加载。

## 使用

从 Chrome 工具栏打开扩展，或展开页面上的“汉化助手”，可以设置两个独立开关：

| 开关 | 用途 |
| --- | --- |
| 精细翻译 | 开启显示中文，关闭恢复原文 |
| AI辅助问题回答 | 显示或隐藏复杂概念旁的问号 |

两个开关自动保存，并在扩展弹出页与页面助手之间同步。

点击术语旁的 **?**，插件会在原生 Ask Impact 中发送中文问题，要求解释该概念并提供官方帮助链接。已有草稿时会保留草稿并提示；回复由 Impact 生成。

拖动助手左侧的 **⠿ 把手** 可以移动位置；刷新后回到默认位置，也可以点击“恢复默认位置”。把手获得键盘焦点后可用方向键移动，按住 Shift 加快。

名称、金额、日期、输入内容、业务记录与 AI 回复保持原样。账号权限或套餐可能影响可见页面，未收录的文案显示原文。

当前页面适配根据 Demo 账户观察，`app.impact.com` 生产账户尚未检查。

## 更新

源码安装：在 Chrome 扩展页点击“重新加载”，然后刷新 Impact。

ZIP 安装：解压新包，停用旧版，再加载新版目录并刷新 Impact。请确认扩展列表显示的新版本与安装包一致。

常用术语见 [本地化说明](LOCALIZATION_GUIDE.md)，版本变化见 [CHANGELOG](CHANGELOG.md)。
