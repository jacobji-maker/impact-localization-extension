# impact.com助手

为 Impact 品牌端提供中文界面和术语帮助的 Chrome 插件，支持 `demo.impact.com` / `app.impact.com`。

当前开发候选为 **0.9.10**，累计8551条限定词条／161个帮助主题。此版补七种题型选中后的标签，以及多选、下拉列表、单选的选项区正文和添加按钮；10个实采状态22处固定Text。源码、合成、交付与正常页验收分别记录，完整平台仍在逐步补齐。

## 功能

- 翻译导航、菜单、筛选和表单，覆盖已适配的伙伴、合同、活动、素材、商品、报表等界面。
- 术语问号调用原生 Ask Impact，用中文解释概念并提供官方帮助链接。
- 翻译与 AI 辅助可独立开关，设置自动保存，助手可拖动。
- 助手内的“上线指引”提供配置和追踪验证说明，以及清单功能目录；页面到达、操作声明与实际业务成功分别判断。
- 翻译已适配的原生Checklist固定界面和嵌入说明；指引记录与实际配置、验证结果分别判断。

汉化在本地执行，关闭后恢复原文；业务数据、输入内容和 AI 回复保持原样。未收录文案显示原文，实测页面与未测范围以当前状态为准。

开发版本与实测范围统一见[项目当前状态](PROJECT_STATE.md)，立即任务见[下一步](NEXT_TASK.md)。接手开发先读[交接指南索引](docs/handoff-090/README.md)，按需查看架构、操作、开发和验收路径。安装仅使用dist中已实际产出并通过核验的同版目录，不把源码或历史报告视为当前交付。

术语与实现边界见[本地化说明](impact-cn-mod/LOCALIZATION_GUIDE.md)，平台含义参考[Impact官方品牌帮助](https://help.impact.com/brand)。官方资料与模型复核不替代正常页验收。

0.9.10的新22处已在正常Demo页逐项读回，原生输入属性保持；公开仓库附[固定文案合成样例与运行说明](tests/fixtures/custom-field-selection-0910/README.md)。这不代表app域对应范围或全平台已通过。

## 构建与安装

需要 Python 3；在仓库根目录运行 `python3 scripts/package-extension.py`，生成同版本 ZIP。源码目录 `impact-cn-mod/` 包含根 manifest 与全部扩展资源；本地交付使用核验后的 ZIP 及对应解压目录。`dist/`、浏览器会话与本地验收材料不纳入公开源码。

以下为交付目录的安装方式；实际加载版本与实页结果以状态页为准。

1. 使用PROJECT_STATE列明已核验的ZIP或同版解压目录；ZIP需先解压。
2. 用户手动打开 `chrome://extensions/`，开启开发者模式。
3. “加载已解压的扩展程序”，选择直接包含 `manifest.json` 的同版目录，只启用一个版本。
4. 登录 Impact，原站语言设为 English 并刷新；通过“impact.com助手”调整开关。

更新后手动重新加载扩展，保留未保存表单再刷新正常页面。[操作指南](docs/handoff-090/OPERATOR_GUIDE.md) · [开发与打包](docs/handoff-090/DEVELOPMENT_GUIDE.md) · [更新记录](impact-cn-mod/CHANGELOG.md)

展开“impact.com助手” → “上线指引”，用上一项、下一项连续查看。定位会先提示展开所属分组；验证页帮助侧栏挡住正文时，先指关闭按钮，由你手动关闭后继续指向测试入口。测试工具内可定位已观察的固定按钮；打开测试链接后由你在店铺下单，完成后返回Impact核对本次测试订单。退款与审核没有定位或操作声明。页面到达、用户声明与业务结果分别判断；真实 Shopify 连接、订单／退款与生产业务流程仍未验证。
