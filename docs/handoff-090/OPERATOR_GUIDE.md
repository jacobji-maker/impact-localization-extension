# 插件加载与日常操作指南

本指南面向使用插件的用户。它说明如何加载、辨认运行版本、使用两个开关和指引，以及如何报告问题。当前包的实际验收状态只见[PROJECT_STATE.md](../../PROJECT_STATE.md)，本指南不代表全平台全部页面已经通过。

## 加载一个版本

1. 使用`dist/`中的同版解压目录，确认其根目录有`manifest.json`。ZIP先解压，不选择Downloads外层目录或ZIP本身。
2. 由用户手动加载或更新扩展。开发助手不自动访问或绕过扩展管理页。
3. 在正常Impact页面打开助手设置，核对实际显示版本。文件版本、扩展包版本和旧页面正在运行的版本可能不同。
4. 已打开的旧页若有未保存表单，先保留它；可新开一个只读Impact页确认新版本。准备好后再刷新原页。

一个版本包覆盖现有demo与app两个Impact域名的受支持组件，无需为通知、设置、清单或测试列表分别安装。组件按页面与结构自动匹配，不能据“已加载”推定所有正文、Program或生产页面均验收通过。

## 两个开关怎样配合

| 精细翻译 | AI辅助问题回答 | 预期表现 |
| --- | --- | --- |
| 开 | 开 | 固定文案中文；适用的单概念问号可用 |
| 关 | 开 | 固定Text恢复原文；已有AI问号可保留 |
| 开 | 关 | 中文继续显示；AI概念入口关闭，不发送新问题 |
| 关 | 关 | 固定Text恢复原文；AI概念入口关闭 |

两个开关独立持久保存，已加载的相关页面会同步。测试后恢复原状态即可，不需要反复开关才能触发正常菜单翻译。助手拖动位置只在当前页面保留，刷新后复位。

## 哪些英文应保留

自定义清单名、Program名、事件名称、订单号、机器ID、金额、日期、输入值、协议代码和AI回复保持原样。已确认的固定标题、设置说明、按钮和菜单Text才按语境翻译。输入框placeholder等属性不属于当前Text-only实现范围。

共享导航的固定产品标题采用“合作管理／招募伙伴／多维分析／风险防护”，Checklists固定标签采用“配置清单”。旁边的清单自定义名称与进度不应跟着改写。

## 页面与浮层的自动翻译

普通导航、折叠菜单、已挂载的隐藏固定Text及开放Shadow重新出现时，插件会重新判定适用范围。菜单刚挂载的即时读数可能早于观察队列，确认目标稳定后再判断漏译。

展开栏、悬浮菜单和隐藏副本是不同表示。报告“悬浮仍英文”时，应核实际可见浮层，不能用旁边已中文的展开栏替代。关闭Shadow及未采集组件不据其它位置通过而自动算覆盖。

## 上线指引与概念问号

“上线指引”提供当前位置、步骤说明及原生入口定位。阅读或勾选操作声明不代表配置已保存、测试成功或业务已审核。Program或页面变化后，旧声明和定位应失效；无法可靠核对来路时保留只读说明，不自动恢复旧任务。

问号仅向已有Ask Impact询问单一复杂概念，并要求官方资料链接。已有草稿或禁用输入框应受保护；不复制私人业务行作为问题，也不伪造AI答复。

Save／Next可能保存配置；启动新测试、生成或执行测试、订单、支付退款、安装授权和审核不属于普通翻页。需要这些业务操作时，由用户明确指定具体范围。

## 怎样报告一个新问题

给出正常页面的固定文案、操作顺序、实际版本和两个开关状态，说明它在浮出菜单、展开栏、iframe还是正文。不要发送账户密码、企业会话、完整业务行或私人输入值。开发者会只采最小公开结构，保存真实失败，再做定向修复与回测。

若需要切Program或页面，开发者应先把原值仅存内存，结束读回恢复；用户中途自行刷新或更改现场时，以用户最新操作为准，不复原到失效旧页面。
